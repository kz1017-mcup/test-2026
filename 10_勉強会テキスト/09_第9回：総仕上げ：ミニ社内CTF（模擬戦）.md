## 1. CTFの1日の流れ

実際のCTF大会は、おおむね次のような流れで進みます。

| フェーズ | やること |
| --- | --- |
| ① 開始前 | チーム分け・役割の確認、CTFdへのログイン確認、ツール（ブラウザ・CyberChefなど）の準備、連絡手段（Discord等）の確認 |
| ② 開始〜序盤 | まず**全問題のタイトルと配点をざっと眺め**、解けそうな問題から手を付ける |
| ③ 中盤 | 解けた問題のフラグを提出してポイントを積み上げる。詰まった問題は一度置いて別の問題へ |
| ④ 終盤 | 残り時間を見ながら、解けそうな問題に絞って最後まで粘る |
| ⑤ 終了後 | スコアボードで結果を確認し、**解けなかった問題の解き方を振り返る** |

## 2. CTFd（スコアサーバー）の使い方

今回の大会は、第1回で紹介した「スコアサーバー」にあたる **CTFd** を使います。画面の基本的な使い方は次の通りです。

### 🧭 主な画面

| 画面 | 用途 |
| --- | --- |
| **Challenges（問題一覧）** | 全問題がジャンル別・配点付きで並びます。解きたい問題のカードをクリックすると詳細が開きます |
| **Scoreboard（順位表）** | 全チームの現在の得点と順位を確認できます |
| **Team（チーム）** | 自分のチームのメンバー・得点・解いた問題を確認できます |

### 🚩 フラグの提出方法

1. 問題カードをクリックして詳細画面を開きます。
2. **問題文**を読み、必要に応じて添付ファイルのダウンロードや、指定されたURL・`nc`コマンドへの接続を行います。
3. 見つけたフラグ（`flag{...}`の形式）を入力欄に**カッコも含めてそのまま**貼り付けます。
4. **「Submit」** を押します。正解なら得点が加算され、不正解ならメッセージが表示されます。

> ⚠️ **フラグ提出の注意点**
> * 前後に**余計なスペースや改行が入っていないか**確認しましょう（コピー&ペースト時に混ざりがちです）
> * 大文字・小文字は区別されます
> * 間違えた提出を**短時間に連続で行うと、一時的に提出できなくなる**（レート制限）設定の大会もあります。慌てて何度も試さず、落ち着いて確認してから提出しましょう
> * 解けたら、**チームの誰か1人が提出すれば**チーム全員の得点になります（誰が提出したかはチーム内で共有しておきましょう）

### 🎯 配点の見方

問題には難易度に応じた配点が付いています（難しい問題ほど高得点）。大会によっては、第1回で紹介した**ダイナミックスコーリング**（解いたチームが増えるほど配点が下がる仕組み）が採用されることもあります。

## 3. チーム戦の進め方（3名・対面で取り組むコツ）

今回は**同じ場所に3名で集まる**形式です。対面ならではの強みを活かしましょう。

### 👥 役割分担の考え方

3名全員が同じ問題に取り組むと非効率です。たとえば次のように分担します。

| 役割 | 内容 |
| --- | --- |
| **得意ジャンルの担当** | 各自が得意・好きなジャンルを中心に問題を選ぶ（例：Aさん＝Web/Crypto、Bさん＝Network/Forensics、Cさん＝OSINT/PWN） |
| **司令塔（進行役）** | 全体の進捗・残り時間を見て「そろそろこの問題は諦めて次へ行こう」と声をかける人。提出担当を兼ねても◎ |
| **ヘルプ役** | 詰まっている人の画面を見て、一緒に考える（**複数人の視点で見ると、一人では気づけなかったことが見つかる**のがCTFの醍醐味です） |

全員が「全ジャンルを均等に解く」必要はありません。**チームとして多くの問題を解く**ことが目標です。

### 🗣️ 対面ならではのコミュニケーション

* **画面を見せ合う**：怪しいデータが見つかったら、すぐ隣の人に画面を見せて意見を聞く
* **声に出して考える**：「このファイル、拡張子と中身が合ってないかも」と口に出すだけで、別の人が気づいてくれることがあります
* **ホワイトボードや付箋を使う**：試したこと・分かったこと・次にやることを書き出しておくと、行き詰まったときに状況を整理できます

### 📝 チーム共通のメモを用意する

同じ問題を2人が別々に試して時間を無駄にしたり、「さっき試したツールは何だったっけ？」となったりするのを防ぐため、**共有メモ**（Discordのチャンネル、GitHubのIssueなど、おまけ①で練習したもの）を用意しましょう。

```
【問題名】 Web：ひらけゴマ
【担当】   Aさん
【状況】   ログイン画面にSQLiっぽい入力欄あり。' を入れたらエラー
【試したこと】 ' OR '1'='1 → 弾かれた
【次にやること】 大文字小文字を変えて試す
```

このように「担当・状況・試したこと・次にやること」を書いておくだけで、チームの動きが見違えます。

## 4. 問題の選び方・時間配分

### 🎯 まず全体を眺める

始まったらいきなり1問目から取り組まず、**全問題のタイトル・ジャンル・配点・解答チーム数**にざっと目を通しましょう。

* 解答済みチームが多い問題は、**易しい問題**の可能性が高い
* 自分たちの得意ジャンルの初級問題から手を付けると、**早い段階で確実にポイントを稼げる**

### ⏱️ 1問あたりの時間の目安

* **「15〜20分やって進展がなければ、一度置く」**というルールをチームで決めておくのがおすすめです
* 詰まった問題に固執すると、他の取れる問題を取り逃がします
* 置いた問題も、他の問題を解いて新しい知識や発想が出てきたあとに再挑戦すると、意外とあっさり解けることがあります

### 🪜 取り組む順番の基本戦略

1. まず**各ジャンルの初級問題**を、役割分担して一気に片付ける
2. 取れた点数と残り時間を見ながら、**中級問題**に進む
3. 時間に余裕があれば、**上級問題**に挑戦する

上級問題は配点が高いぶん時間もかかります。**初級・中級を取りこぼさないこと**が、結局は一番の得点源になります。

## 5. 詰まったときの対処法

CTFでは「詰まる」のは当たり前です。慌てず、次の手順を試してみましょう。

| 確認すること | 具体例 |
| --- | --- |
| **問題文を読み直す** | タイトルや問題文自体が、ヒントになっていることが非常に多いです |
| **添付ファイル・URLを改めて調べる** | 見落としているファイルやページがないか、ソースコード・メタデータまで見たか確認する |
| **これまで学んだツールを一通り試す** | 後述の「ツール早見表」を見ながら、順番に試してみる |
| **ググる** | 第1回で学んだ通り、「分からない単語＋仕組み/復号/ツール」で検索する（CTFは暗記テストではありません） |
| **公式ヒント（Hints）を見る** | 問題にヒントが用意されている場合は、遠慮せず見てOK（ただし得点が減る設定の大会もあるので、事前にルールを確認しましょう） |
| **チームメイトに話しかける** | 状況を声に出して説明するだけで、解決の糸口が見つかることがあります |

## 6. ジャンル別ツール早見表

これまでの8回で紹介したツールを、ジャンル別にまとめました。迷ったらここを見返しましょう。

| ジャンル | 最初に試すこと | 主なツール |
| --- | --- | --- |
| **Web**（第3回） | ページのソース・開発者ツール（F12）を見る、Cookieを見る | ブラウザの開発者ツール、jwt.io |
| **Crypto**（第4回） | 何の暗号・エンコードかを見極める | CyberChef（Magic機能）、dCode.fr（Cipher Identifier）、CrackStation |
| **Network**（第5回） | Follow Stream、表示フィルタで絞り込む | Wireshark |
| **OSINT**（第6回） | 逆画像検索、EXIF、GPS座標 | Yandex画像検索、Jimpl、Googleマップ、Wayback Machine |
| **Forensics**（第7回） | まずは`file`と`strings`で正体を疑う | `file`/`strings`、Hexエディタ（HexEd.it）、Aperi'Solve、StegOnline、CyberChef |
| **PWN**（第8回） | ソースコードを読み、入力を信用している箇所を探す | `nc`、ソースコードの読解 |

> 💡 **共通の鉄則**
> * 怪しい文字列を見つけたら、まずCyberChefに貼り付けてみる
> * 拡張子や見た目を鵜呑みにしない（Forensicsの合言葉）
> * フラグ形式（`flag{...}`）で始まる文字列が見つかったら、それが答えの候補

## 7. ルールとマナー

CTFは**許可された環境の中でだけ**行うゲームです。第1回で学んだ「ホワイトハッカーとしての約束」を、今回もしっかり守りましょう。

* **攻撃してよいのは、指定された問題の環境だけ**です。大会の運営サーバー（CTFd）自体や、他のチームのPC・ネットワークを攻撃してはいけません
* **他チームにフラグや解き方を教えない・教わらない**（大会中は、チーム内だけで相談します）
* **問題サーバーに過度な負荷をかけない**（無差別な大量リクエストなど、他の参加者の迷惑になる行為は禁止です）
* 不明点・不具合を見つけたら、自分で何とかしようとせず**運営（主催者）に相談**しましょう
* OSINT問題では、実在の人物・企業に連絡・接触しないこと

---

## 8. 大会終了後にやること

CTFで一番成長できるのは、実は**大会が終わったあと**です。

1. **解けなかった問題の解説（Writeup）を読む**：第1回で学んだ通り、「へぇー！こうやって解くのか！」という体験を積み重ねることが上達の近道です
2. **チーム内で振り返る**：どの問題で時間を使いすぎたか、どのツールが役に立ったかを話し合う
3. **解けた問題も、別の解き方がなかったか考える**：他のチームのやり方を聞いてみるのも勉強になります
4. **picoCTFなどの常設CTFで復習する**：今回触れたジャンルで、気になったものを自習してみましょう

### 📌 模擬戦のルール

* 問題は**最初から全て公開**されています。好きな順番で挑戦してください
* 難易度の目安は、**初級＝100点、中級＝200点、上級＝300点**です（picoCTF本来の配点とは異なります）
* 全部を解く必要はありません。**チームで力を合わせて、1問でも多くのフラグを見つけ出しましょう！**
* 解説は載せていません。詰まったら、前半の「詰まったときの対処法」を見返しましょう

### 📌 事前に確認しておくこと

* OSINT以外の問題のリンクは**CyLab Security Academy**（第2回で登録したサイト）のものです。OSINTは**TryHackMe**（第6回で登録したサイト）のものです。**チーム3名とも、事前に両方のサイトにログインできることを確認**しておいてください
* OSINT以外のフラグは、問題ごとに**CyLab上で提出**します。形式は`picoCTF{...}`です（本番のCTFdでは`flag{...}`の形式になる想定です）
* **Crypto上級の「Play Nice」は、フラグが標準の形式（`picoCTF{...}`）ではありません**。問題文の指示に従って、そのまま提出してください
