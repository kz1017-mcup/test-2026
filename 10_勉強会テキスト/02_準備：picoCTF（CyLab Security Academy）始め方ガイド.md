# 🚀 picoCTF（CyLab Security Academy）始め方ガイド

今回は、世界中で使われているCTF学習プラットフォーム **「picoCTF」** のアカウント作成手順と、基本的なサイトの操作方法を解説します！

レクチャで学んだ知識を試したり、個人練習で問題を解いたりするメインの場となりますので、一緒に登録と操作確認を行っていきましょう。

---

## 1. picoCTFとは何か

**picoCTF** は、アメリカの名門 **カーネギーメロン大学（CMU）のCyLab Security Academy** が運営する、世界最大級の無料CTF学習プラットフォームです。

* **完全無料で遊び放題:** 初心者向けから上級者向けまで、何百問もの問題が常に公開されています（常設CTF「picoGym」）。
* **世界基準の問題クオリティ:** 世界中のセキュリティ学習者が利用しており、実戦的な問題が豊富です。
* **英語サイトですが大丈夫！:** 画面は英語ですが、Google Chromeなどの「日本語に翻訳」機能を使えば問題なくプレイできます。

## 2. アカウント作成方法

それでは、アカウントを作成しましょう。登録作業に入る前に、**最も重要な注意事項**があります。

> ⚠️ **【超重要】メールアドレスに関する注意点**
> 登録に使用するメールアドレスは、**必ず個人所有のメールアドレス（GmailやYahoo!メールなど）** を使用してください。
> 業務研修や社内勉強会であっても、社外のCTFサービスに**会社のメールアドレス（`@会社ドメイン`）を登録することはセキュリティ・運用上の観点から推奨されません**。プライベートなメールアドレスをご用意ください。

### 📝 登録手順（サインアップ）

1. ブラウザで **<https://cylabacademy.org/>** にアクセスします。
2. 画面右上にある **「Sign Up」** をクリックし、遷移したページで再度画面右上にある **「Sign Up」** をクリックします。

3. 登録フォームに以下の情報を入力します：
* **Username:** 好きなユーザー名（アルファベット・数字）
* **Email:** **私有のメールアドレス**
* **Password:** パスワード（忘れないように控えをとってください）

4. 生年月日や国籍（Japan）などの基本情報を選択し、利用規約にチェックを入れます。
5. **「Sign Up」** ボタンを押すと、入力したメールアドレス宛に確認メール（Verification Email）が届きます。
6. メール内の認証リンク（URL）をクリックすれば、アカウント登録完了です！

## 3. サイトの構成と画面の見方

ログイン後、メインで使うのは **「picoGym（常設問題エリア）」** です。

画面上部のメニューから **「Practice」**（または **「picoGym」**）を選択すると、問題一覧画面が開きます。

### 🔍 画面の見方と便利な機能

* **カテゴリ絞り込み（Category）:**
* `Web Exploitation`（Web）、`Cryptography`（暗号）、`Forensics`（ファイル解析）など、ジャンルごとに問題を絞り込むことができます。


* **難易度・ソート機能（Sort by / Difficuly）:**
* 最初は **「Easy」** で絞り込んだり、**「Solves（解けた人数）」** が多い順に並び替えるのがおすすめです（多くの人が解けている＝簡単な問題です）。


* **問題カード（Challenge Card）:**
* 一覧に並んでいるカードには「問題タイトル」「獲得ポイント」「ジャンル」が表示されています。

## 4. 各問題を解くときの操作手順

実際に問題を1問選んで解く際の流れを解説します。

### ① 問題カードをクリックして開く

気になる問題カードをクリックすると、問題の詳細ウィンドウが開きます。

* **Description（問題文）:** どのような謎や課題があるかが書かれています。
* **リンクやファイル:** 問題文の中に青い文字のリンク（WebサイトのURL）や、ダウンロード用ファイル（`static.zip` など）が貼られています。ここからターゲットにアクセスします。

### ② ヒント（Hints）の活用

問題文の下に **「Hints」** というアコーディオンボタンがあります。

* クリックすると、問題作成者からの**公式ヒント**が表示されます。
* 初心者のうちは詰まったらどんどんヒントを見てOKです！解き方の方向性を掴みましょう。

### ③ フラグの提出（Submit Flag）

問題の答え（フラグ）が見つかったら、画面下の入力欄に入力します。

1. **`picoCTF{...}`** の形式でフラグをそのまま入力します（カッコも含めて全角/半角に注意して入力してください）。
2. **「Submit Flag」** ボタンを押します。
3. 正解すると **「Correct!」** と緑色のアニメーションが表示され、アカウントにポイントが加算されます！
4. 一度正解した問題には、カードに**緑色のチェックマーク**がつきます。

## 5. 補足：Webシェル（Web Shell）について

問題によっては「Linuxのコマンドを使ってファイルを解析する」というものがあります。

自分のPCにLinux環境（UbuntuやWSLなど）が入っていなくても、picoCTFの画面右上にある **「Web Shell」** ボタンを押すと、**ブラウザ上でそのまま動くLinuxターミナル** を無料で起動できます。

今後のレクチャでLinuxコマンドを扱う際に使用しますので、「ブラウザだけでコマンド操作もできるんだな」ということだけ覚えておけばバッチリです！
